# Problem-Solving Skills

My C++ data-structures-and-algorithms practice log. The goal is consistent, concept-first progress: understand a pattern, implement it cleanly, and then solve increasingly independent problems.

## Current progress

The repository currently contains introductory pattern-printing exercises in `DSA/`. It is intentionally an early-stage learning repository, not a collection of advanced competitive-programming solutions.

## Structure

```text
DSA/
├── 1_star1.cpp
├── 2_star2.cpp
├── 3_star3.cpp
└── 4_star4.cpp
```

## Compile and run

Using g++:

```bash
g++ -std=c++17 DSA/1_star1.cpp -o pattern
./pattern
```

On Windows PowerShell:

```powershell
g++ -std=c++17 DSA/1_star1.cpp -o pattern.exe
./pattern.exe
```

## Planned progression

1. C++ problem-solving basics and pattern exercises
2. Arrays, strings, and hashing
3. Two pointers, sliding window, and binary search
4. Linked lists, stacks, and queues
5. Trees, heaps, graphs, and dynamic programming

## Practice principles

- Write the first approach before optimizing
- Record time and space complexity
- Revisit problems instead of memorizing solutions
- Prefer readable C++ over clever shortcuts
